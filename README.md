# 朗读器（tts-reader）

本地文档朗读应用：打开 Word / PDF / TXT / WPS，用系统语音（或可选引擎）朗读。

## 3.2 功能

- **导出音频**：将当前文档合成为 **WAV（24 kHz 16-bit 单声道）** 或 **M4A（AAC 约 48 kbps）**。可选在开头朗读声明「本音频由人工智能生成」。导出走与播放相同的 TTS 合成路径，不是屏幕录制。
- **默认系统语音**。Edge 神经语音为**实验性可选项**（设置 → 高级），默认关闭。讯飞为用户自行填写的 API 密钥，不是默认引擎。本版本不包含 Azure。
- 隐私说明见 [docs/privacy.html](docs/privacy.html)（应用内「关于」可打开）。

## 开发

```bash
npm install
npm start
```

打包：`npm run build:mac` / `npm run build:win`（需要相应平台）。编码自检：`npm test`。

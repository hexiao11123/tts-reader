隐私说明

朗读器 v3.2 · 本文说明应用如何处理你的文件与密钥。本应用不提供用户账号。

本地文件

你打开的 Word、PDF、TXT、WPS 等文档只在本机解析和朗读。应用不会为此创建云端文稿库，也不会把整份文档上传到朗读器自己的服务器（本应用没有用户账号服务）。

导出的 WAV / M4A 保存在你选择的本地路径。

没有用户账号

朗读器不要求注册、登录或订阅账号。没有个人资料页，也没有用于识别你身份的应用内账号系统。

可选的讯飞密钥

讯飞不是默认语音引擎。只有当你在设置中自行填写讯飞开放平台的 AppID、APIKey、APISecret 时，应用才会使用讯飞在线合成。

这些密钥保存在本机用户数据目录，并在操作系统支持时用系统加密接口（safeStorage）加密。使用讯飞音色时，待合成的文本会发送到讯飞语音服务；未配置密钥则不会请求讯飞。

系统语音（默认）

默认使用操作系统自带的语音。合成在本机完成，不经过朗读器的服务器。

实验性 Edge 神经语音

Edge 神经语音默认关闭。若你在「设置 → 高级」中主动启用，待合成的文本会发送到 Microsoft Edge 在线语音接口。该接口为非官方实验能力，可能不稳定或失效。不启用则不会走这条路径。

联系

若对本文有疑问，请通过软件发行渠道联系发行方。本页可在应用「设置 → 关于」中再次打开。
